# 37. 高度语义

统一：

```
absoluteAltitude
relativeAltitude
groundElevation

```

含义：

- absoluteAltitude：相对于参考椭球面的绝对高度；
- relativeAltitude：相对于起飞点的高度；
- groundElevation：地面高程。

------

# 38. DJI字段映射

当前DJI设备属性定义：

```
elevation
→ relativeAltitude

height
→ absoluteAltitude

```

即：

```
DJI elevation
= Relative takeoff point altitude

DJI height
= Absolute height / Ellipsoid-related absolute altitude

```

该映射以当前DJI Cloud API设备属性文档为准。

# 79. 最终治理原则

正式执行：

> **一个定义只有一个拥有者。**

> **一个枚举只有一个机器来源。**

> **一个接口只有一个OpenAPI定义。**

> **一个数据库Schema只有一个Migration来源。**

> **一个算法参数只有一个版本化配置来源。**

> **一个验收指标必须存在唯一基线版本。**

同时：

> **旧版本可以保留，但只能作为历史证据，不能与当前版本并列生效。**

最终形成：

```
业务文档
↓
技术设计
↓
数据库
↓
协议
↓
算法
↓
API
↓
代码
↓
测试
↓
部署

```

全部使用同一套冻结语义。
