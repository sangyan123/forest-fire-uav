因此：


# 34. F04参数基线

F04：

```
RGB
Thermal
Temporal
Spatial

```

V1权重：

```
RGB      = 0.35
Thermal  = 0.35
Temporal = 0.15
Spatial  = 0.15

```

计算：

```
VerificationScore
=
0.35 × RGB
+
0.35 × Thermal
+
0.15 × Temporal
+
0.15 × Spatial

```

决策：

```
Score ≥ 0.80
→ CONFIRMED

Score < 0.50
→ FALSE_ALARM

0.50 ≤ Score < 0.80
→ UNCERTAIN

```

# 38. DJI字段映射

当前DJI Cloud API设备属性文档明确：

```
elevation
= Relative takeoff point altitude

height
= Absolute height
= Relative to Earth ellipsoid

```

因此统一映射：

```
DJI elevation
→ relativeAltitude

DJI height
→ absoluteAltitude

```

该定义以DJI当前Cloud API设备属性文档为准。

------

# 39. DJI航线高度补充规则

DJI WPML还区分：

```
相对起飞点高度
EGM96海拔高度
AGL相对地面高度
椭球高

```

因此内部：

```
TargetPoint.altitude

```

必须与：

```
altitudeMode

```

同时存在。

例如：

```
ELLIPSOID
RELATIVE_TO_TAKEOFF
AGL

```

不能出现：

```
altitude = 120

```

却不说明120的参考系。

DJI文档也明确区分目标点使用WGS84椭球高的接口和相对起飞点高度的安全起飞高度。

# 76. 最终治理原则

本项目正式执行以下原则：

> **一个定义只有一个拥有者。**

> **一个枚举只有一个机器来源。**

> **一个接口只有一个OpenAPI定义。**

> **一个数据库Schema只有一个Migration来源。**

> **一个算法参数只有一个版本化配置来源。**

> **其他文档只能引用，不能自行复制后修改。**
