# 24. UAV高度语义冻结

统一内部字段：

```
absoluteAltitude
relativeAltitude
groundElevation

```

含义：

### absoluteAltitude

无人机相对于参考地球椭球面的绝对高度。

### relativeAltitude

无人机相对于起飞点的高度。

### groundElevation

无人机所在位置的地面高程。

------

# 25. DJI字段映射冻结

DJI当前文档中：

```
height
= 绝对高度 / 椭球高

elevation
= 相对起飞点高度

```

因此统一映射：

```
DJI height
→ absoluteAltitude

DJI elevation
→ relativeAltitude

```

该映射以当前DJI Cloud API文档为依据。

注意：

> DJI不同接口的字段语境可能有所不同，因此Adapter必须按具体API字段文档做映射，不能根据字段名猜测。

# 26. 目标高度语义冻结

内部：

```
TargetPoint.altitudeMode

```

允许：

```
ELLIPSOID
RELATIVE_TO_TAKEOFF
AGL

```

并要求：

```
TargetPoint.altitude

```

必须与：

```
altitudeMode

```

同时出现。

这样避免：

```
120m

```

到底是：

```
相对起飞点120m
还是椭球高120m

```

的歧义。

DJI Cloud API的部分目标点接口明确使用WGS84椭球高，而安全起飞高度使用相对起飞点高度，因此内部协议必须把高度参考系显式化。

# 30. F01检测阈值冻结

定义三个概念：

```
T_candidate
T_alert
T_confirm

```

第一版默认：

```
T_candidate = 0.40
T_alert     = 0.60
T_confirm   = 0.80

```

解释：

```
confidence < 0.40
→ 忽略

0.40 ≤ confidence < 0.60
→ Candidate

0.60 ≤ confidence < 0.80
→ Alert Candidate

confidence ≥ 0.80
→ High Confidence

```

最终火情确认仍然不能只由F01决定，而必须进入F04核验。

# 32. F04核验权重冻结

统一：

```
w1 = RGB
w2 = Thermal

w4 = Spatial

```

V1基线：

```
w1 = 0.35
w2 = 0.35
w3 = 0.15
w4 = 0.15

```

计算：

```
VerificationScore
=
0.35 × RGB
+
0.35 × Thermal
+
0.15 × Temporal
+
0.15 × Spatial

```

初始决策：

```
Score ≥ 0.80
→ CONFIRMED

Score < 0.50
→ FALSE_ALARM

0.50 ≤ Score < 0.80
→ UNCERTAIN

```
