# 9. 数据集划分原则

禁止随机把相邻视频帧简单拆到：

```
train
val
test

```

因为这样容易造成数据泄漏。

推荐按：

```
地点
时间
航线
火灾事件

```

分组。

例如：

```
Location A
 ├── Train

Location B
 ├── Validation

Location C
 └── Test

```

这样才能测试跨区域泛化能力。

统一拆分规则（00基线 V1.3 第53章，2026-09-27 回写）：

```
TRAIN / VALIDATION / TEST 初始比例 = 70% / 15% / 15%

```

并且必须按：

```
航次
场景
时间段
地理区域

```

进行组级拆分；禁止同一段视频帧级随机打散，防止数据泄漏。每个数据集版本（第 31 章）必须记录其组级拆分清单，保证实验可复现。

# 10.7 后处理

不能单帧直接报警。

增加：

```
Confidence threshold
NMS
Temporal persistence
Spatial consistency

```

例如：

```
连续 3 / 5 帧出现
+
目标中心偏差 < threshold
=
稳定检测

```

阈值必须通过验证集确定。

V1 工程基线（00基线 V1.3 第33章）冻结值，落地于 `fire-detection-config-v1.0`：

```
T_candidate = 0.40
T_alert = 0.60
T_confirm = 0.80

TEMPORAL_WINDOW = 5 帧
MIN_POSITIVE_FRAMES = 3

```

即保留上述“连续帧验证”机制：在 5 帧滑动窗口内出现 ≥ 3 个正帧方可升级告警；三档置信阈值（候选/告警/确认）按上表冻结，后续调整必须走实验协议与参数版本化流程（见第 30 章），禁止直接手改。

# 12.3 基本算法

采用：

# 射线—地面交会

流程：

```
Pixel
 ↓
相机归一化坐标
 ↓
Camera Ray
 ↓
Camera → Gimbal
 ↓
Gimbal → UAV Body
 ↓
Body → World
 ↓
Ray
 ↓
DEM / Ground Intersection
 ↓
Latitude / Longitude

```

------

# 12.4 核心公式

相机坐标：

```
x = (u - cx) / fx
y = (v - cy) / fy

```

形成：

```
ray_camera = [x, y, 1]

```

通过旋转矩阵：

```
ray_world = R_world_body
            · R_body_gimbal
            · R_gimbal_camera
            · ray_camera

```

随后求：

```
CameraPosition + t * ray_world

```

与地面平面或 DEM 的交点。

# 13.1 目标

```

```

------

# 13.2 第一阶段

不要一开始训练复杂多模态 Transformer。

先采用：

```
RGB Score
Thermal Score
Temporal Score
Spatial Score

```

加权融合：

```
FinalScore =
w1*RGB
+
w2*Thermal
+
w3*Temporal
+
w4*Spatial

```

参数通过验证集学习。

V1 工程基线（00基线 V1.3 第34章）冻结权重，落地于 `verification-config-v1.0`：

```
RGB = 0.35
Thermal = 0.35
Temporal = 0.15
Spatial = 0.15

```

即：

```
VerificationScore
=
0.35 × RGB
+
0.35 × Thermal
+
0.15 × Temporal
+
0.15 × Spatial

```

决策阈值：

```
VerificationScore ≥ 0.80 → CONFIRMED
VerificationScore < 0.50 → FALSE_ALARM
0.50 ≤ VerificationScore < 0.80 → UNCERTAIN

```

后续权重调整必须走实验协议与参数版本化流程（见第 30 章），禁止直接手改。

------

# 13.3 第二阶段

模型融合：

```
RGB Encoder
       │
       ├───────┐
       ▼       │
Thermal Encoder
       │       │
       └──Fusion
           ↓
        Classifier

```

候选：

```

```

# 13.4 时间一致性

```

> 换一个森林、换一个天气、换一架无人机就失效。

2025 年 Boreal Forest Fire 数据集研究明确观察到：使用其他区域烟雾数据训练的模型，在不同地区的森林烟雾场景上精度可能发生非常明显的下降，因此本项目必须做跨地区、跨环境验证。([nature.com](https://www.nature.com/articles/s41597-025-05634-0?utm_source=chatgpt.com))

所以验收必须包含：

```
