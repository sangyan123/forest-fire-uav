# 1. 文档目的

建立整个森林防火无人机智能系统的测试和验收标准。

测试对象包括：

```
UAV
UAV Gateway
Backend
AI Service
Database
Message System
Mission
Dispatch
Frontend
Vendor Adapter

```

测试重点不是只有“接口能不能返回200”。

本项目最终必须验证：

> **系统能不能从无人机数据出发，经过AI分析和业务决策，再反向控制无人机完成任务。**


-  Incident可生成；

-  能完成完整核验链；

# 32. 候选指标转正机制

F05～F12候选指标必须经过：

```
06算法方案
+
08测试方案
+
数据集版本
+
实验结果
+
技术评审

```

转化为正式V1验收指标。

所有指标必须携带版本号：

```
metricBaselineVersion

```

例如：

```
algorithm-metrics-v1.0

```

机器来源：

```
docs/00-doc/baseline-metrics.yaml

```

数据集划分：

```
TRAIN / VALIDATION / TEST = 70% / 15% / 15%

```

并按：

```
航次
场景
时间段
地理区域

```

进行组级拆分。

禁止帧级随机打散。
