# 2. 项目总体实施思路

本项目采用：

> **“先统一协议 → 再模拟设备 → 再打通业务闭环 → 再接入真实算法 → 再做智能决策 → 最后接入真实无人机并生产化”的研发路线。**

不采用：

```
数据库全部开发完
→ 后端全部开发完
→ AI全部开发完
→ 前端全部开发完

```

这种横向开发方式。

采用：

```
一个完整业务闭环
↓
测试
↓
验证
↓
扩展能力
↓
继续下一个闭环

```

------

# 3. 完整研发路线

项目整体划分为 Phase 0～Phase 9 共十个实施阶段（Phase 9 拆分为 9A/9B）：

```
Phase 0 项目初始化
↓
Phase 1 基础设施
↓
Phase 2 UAV统一协议
↓
Phase 3 业务基础
↓
Phase 4 AI第一闭环（F01/F02/F03/F04）
↓
Phase 5 火场闭环（F05/F06，含反向控制闭环，P0/MVP核心闭环完成）
↓
Phase 6 主动决策（F07/F08/F09-Advanced）
↓
Phase 7 高级智能（F12→F11→F10）
↓
Phase 8 测试与验收
↓
Phase 9 真实设备与生产化
   ├── Phase 9A 真实UAV厂商接入
   └── Phase 9B 生产部署与运维

```

其中：

```
Phase 0～5 = 核心MVP阶段（Phase 5完成时P0/MVP核心闭环成立）
Phase 6    = 智能能力扩展（主动决策）
Phase 7    = 高级智能
Phase 8    = 系统验收
Phase 9A   = 真实设备阶段
Phase 9B   = 生产运行阶段

```

> 阶段编号以《00 跨文档设计基线与矛盾修订清单》V1.3 第23章冻结表为唯一版本；P0/P1/P2 仅用于功能优先级（冻结矩阵见同基线第7～8章），Phase 0～9 仅用于开发阶段，二者不得混用。

   ↓
UAV Gateway
   ↓

   ↓
